Состояние (управление прототипом):

Описание

Прототип показывает структуру, состояния, тексты и клавиатуру. Модель документа упрощённая (собственные DOM-операции), в сборке — TipTap. Попробуйте: Tab из «Заголовка» (панель — одна остановка, ← → внутри), Ctrl+B/I/U, Ctrl+K, Ctrl+[ и Ctrl+], таблицу и «Операции с таблицей», Tab между ячейками, Esc затем Tab, Ctrl+Enter, блок кода (Tab — отступ), вставку адреса и адреса через пробел, перетаскивание файла.

Хранимое значение (после нормализации, без служебной разметки), символов по BR-RT-8: 0
